# 06 - Testes

Esta pasta contém os materiais usados para validar o comportamento do agente.

Os testes ajudam a evitar regressões quando prompts, rubricas ou fluxos são alterados.

## O que deve existir aqui
- Conjuntos de prompts de teste (bons, médios e ruins)
- Resultados esperados
- Estratégia de testes manuais ou semiautomáticos

## O que NÃO deve existir aqui
- Prompts de sistema principais
- Scripts utilitários
- Documentação conceitual
