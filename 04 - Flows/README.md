# 04 - Flows

Esta pasta documenta os fluxos de funcionamento do agente.

Os fluxos descrevem **a sequência lógica de decisões e ações** realizadas em cada modo do agente.

## O que deve existir aqui
- Fluxo do Modo A 
- Fluxo do Modo B 
- Fluxo do Modo C
- Estratégia de fallback e erros
- Passos de validação e classificação

## O que NÃO deve existir aqui
- Prompts de sistema completos
- Exemplos de testes finais
- Código utilitário
