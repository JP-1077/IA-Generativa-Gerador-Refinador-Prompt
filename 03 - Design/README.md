# 03 - Design

Esta pasta descreve o **design conversacional e estrutural** do agente dentro do Copilot Studio.

Ela traduz a arquitetura e o conhecimento em comportamentos práticos.

## O que deve existir aqui
- Mapa de tópicos do Copilot Studio
- Estratégia de roteamento entre modos
- Prompts de sistema por modo
- Estrutura das respostas do agente
- Regras de UX conversacional (quando perguntar, quando reescrever)

## O que NÃO deve existir aqui
- Rubricas de avaliação
- Testes ou datasets de validação
- Scripts auxiliares
