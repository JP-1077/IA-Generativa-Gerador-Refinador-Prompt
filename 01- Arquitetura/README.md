# 01 - Arquitetura

Esta pasta documenta a arquitetura lógica do agente de IA.

Ela define **como o agente funciona**, não como ele é implementado tecnicamente em código.

## O que deve existir aqui
- Visão geral da arquitetura do agente
- Descrição dos modos de operação
- Contrato de saída padrão 
- Rubricas de avaliação 
- Guardrails e restrições do agente
- Estratégia de versionamento e evolução

## O que NÃO deve existir aqui
- Prompts finais de sistema
- Exemplos de conversa
- Detalhes específicos do Copilot Studio
