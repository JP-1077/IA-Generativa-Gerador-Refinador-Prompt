# 07 - Scripts

Esta pasta contém scripts auxiliares para manutenção, validação e apoio ao projeto.

São scripts de suporte e não fazem parte do comportamento do agente em produção.

## O que deve existir aqui
- Scripts de validação de arquivos (YAML/JSON)
- Ferramentas de normalização de outputs
- Scripts de apoio a testes ou exportações
- Documentação de uso dos scripts

## O que NÃO deve existir aqui
- Lógica central do agente
- Prompts de sistema
- Regras de negócio
