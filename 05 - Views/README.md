# 05 - Views

Esta pasta descreve como o agente se apresenta para o usuário final.

O foco aqui é **experiência, visualização e formato da resposta**, não lógica.

## O que deve existir aqui
- Estrutura visual das respostas
- Exemplos de saída do agente
- Adaptive Cards (se aplicável)
- Variações de resposta por canal (ex: Teams, Web)

## O que NÃO deve existir aqui
- Regras de decisão
- Rubricas ou critérios de avaliação
- Fluxos de execução
