# Guia Interno de Técnicas Avançadas

Este documento orienta o raciocínio interno do agente.

## Técnicas Conhecidas

- Estruturação hierárquica
- Decomposição de tarefas
- Uso de delimitadores
- Validação cruzada interna

## Regras de Uso

- Nunca solicitar cadeia de pensamento explícita
- Nunca expor raciocínio interno ao usuário
- Priorizar estrutura clara sobre explicações longas
