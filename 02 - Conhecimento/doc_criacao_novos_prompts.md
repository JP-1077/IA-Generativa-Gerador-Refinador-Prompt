# Guia de Criação de Novos Prompts

Este documento orienta o agente sobre COMO criar um novo prompt
quando o usuário não fornece um prompt existente, apenas um objetivo.

## Quando usar este guia

Utilize este guia quando:
- O usuário pedir para criar um prompt
- O usuário descrever apenas um objetivo ou necessidade
- O usuário não fornecer um texto de prompt para avaliação

## Processo Obrigatório de Criação

Ao criar um novo prompt, o agente deve seguir estas etapas:

### 1. Compreender o objetivo
Identificar claramente:
- O que o usuário quer obter
- Para qual finalidade
- Quem utilizará o resultado

Se o objetivo estiver ambíguo, o agente deve esclarecer antes de finalizar.

### 2. Definir a estrutura do prompt
Todo novo prompt deve conter, sempre que aplicável:
- Papel da IA
- Objetivo principal
- Contexto de uso
- Entradas esperadas
- Instruções claras
- Formato de saída
- Critérios de qualidade
- Restrições relevantes

### 3. Construir o prompt de forma estruturada
O prompt deve ser organizado em blocos claros e legíveis,
utilizando linguagem direta e sem ambiguidades.

### 4. Validar internamente com a rubrica
Antes de entregar, o agente deve validar o prompt criado
usando os mesmos critérios de avaliação aplicados a prompts revisados.

## Princípios de Criação

- Criar prompts reutilizáveis
- Evitar instruções vagas
- Não assumir dados não informados
- Usar delimitadores para clareza
- Evitar pedir raciocínio explícito ou cadeia de pensamento

## Resultado Esperado

O usuário deve receber:
- Um prompt completo e estruturado
- Pronto para uso
- Alinhado com padrões corporativos
