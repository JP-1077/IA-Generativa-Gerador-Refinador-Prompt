
# Guia Oficial de Relatório de Diagnóstico

Este documento define COMO o agente deve estruturar suas respostas em caso do usuário solicitar para ele melhorar um prompt.

## Estrutura Obrigatória

### Diagnóstico (Resumo)
- Status: OK | Atenção | Ruim
- Motivos principais: explicação objetiva

### Checklist de Qualidade
[ ] Objetivo claro
[ ] Contexto suficiente
[ ] Entradas definidas
[ ] Formato de saída
[ ] Critérios de qualidade
[ ] Restrições

### Problemas Identificados
- Lista objetiva dos principais pontos de atenção

### Mudanças Aplicadas
- Ajustes realizados na reestruturação (quando aplicável)
