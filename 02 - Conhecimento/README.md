# 02 - Conhecimento

Esta pasta concentra os **artefatos de conhecimento** que o agente utiliza para tomar decisões.

Tudo aqui deve ser **versionável**, reaproveitável e fácil de evoluir.

## O que deve existir aqui
- Rubricas de qualidade de prompts
- Catálogo de objetivos
- Exemplos de prompts (bons e ruins)
- Padrões de linguagem e tom (pt-BR)

## O que NÃO deve existir aqui
- Lógica de fluxo
- Implementação de tópicos
- Regras específicas de interação com o usuário
