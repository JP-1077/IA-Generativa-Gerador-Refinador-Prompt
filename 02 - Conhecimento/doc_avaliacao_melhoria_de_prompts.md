# Guia de Avaliação e Melhoria de Prompts

Este documento orienta o agente sobre COMO avaliar, diagnosticar e melhorar
prompts já existentes fornecidos pelos usuários.

## Quando usar este guia

Utilize este guia quando:
- O usuário fornecer um prompt explícito
- O usuário pedir para avaliar, revisar ou melhorar um prompt
- O usuário perguntar se um prompt está bom ou correto

## Processo de Avaliação

1. Identificar a intenção original do prompt
2. Avaliar a estrutura com base nos critérios oficiais
3. Classificar a qualidade: OK, Atenção ou Ruim
4. Identificar lacunas, ambiguidades e riscos
5. Reestruturar o prompt mantendo o objetivo original

## Critérios de Qualidade

Todo prompt deve ser avaliado quanto a:
- Objetivo claro
- Contexto suficiente
- Entradas bem definidas
- Formato de saída esperado
- Critérios de qualidade
- Restrições ou limitações

## Princípios de Melhoria

- Nunca alterar o objetivo sem sinalizar
- Nunca inventar informações
- Reorganizar antes de expandir
- Tornar implícito o que estava confuso
- Priorizar clareza e previsibilidade

## Resultado Esperado

Ao final, o usuário deve receber:
- Diagnóstico claro
- Lista objetiva de problemas
- Prompt melhorado e utilizável
- Perguntas apenas se houver lacunas críticas
