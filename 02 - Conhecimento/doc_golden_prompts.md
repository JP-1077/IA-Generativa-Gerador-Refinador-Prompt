# Golden Prompts e Benchmarks

Este documento reúne exemplos de prompts considerados padrão-ouro
para uso corporativo com IA.

## Objetivo

Servir como referência para:
- Avaliar qualidade
- Comparar estruturas
- Inspirar melhorias
- Guiar a criação de novos prompts

## O que é um Golden Prompt

Um Golden Prompt:
- Tem objetivo explícito
- Possui estrutura clara
- Define formato de saída
- Contém restrições adequadas
- Gera resultados previsíveis

## Uso pelo Agente

O agente deve:
- Comparar estruturalmente o prompt do usuário com exemplos similares
- Identificar padrões ausentes
- Adaptar estruturas bem-sucedidas ao contexto do usuário

O agente não deve:
- Copiar exemplos literalmente
- Expor benchmarks internos ao usuário
